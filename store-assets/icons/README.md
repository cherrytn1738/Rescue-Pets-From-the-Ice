# Icon drafts

The Robux item icons, 512x512 PNG; `tools/create_products.py` sent each one to Roblox as its pass or product icon (and its gift twin's). Made by `tools/icons/render_icons.py` (headless Blender:
the game's own creature models, the ice pick tiers, a simple ice block and crystal) and `tools/icons/compose_icons.py`
(Pillow: background, glow, outline, sparkles, text). Regenerate with `python tools/icons/compose_icons.py --render`.
`contact_sheet.png` shows them all, each with a 64 px copy to judge how it reads small. Game pass icons show as
circles on the Roblox site, so the badges stay inside the circle.
